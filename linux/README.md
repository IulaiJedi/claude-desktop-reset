# ClaudeReset для Ubuntu (в т.ч. WSL)

Аудит, резервная копия и сброс локальных данных Claude Desktop для Linux (бета) и чистка
«без следов входа» — без вреда для Claude Code: переписки, `CLAUDE.md`, память, навыки и
настройки остаются. Python 3 из коробки Ubuntu, ничего ставить не нужно.

## Как запустить

```bash
cd путь/к/linux
./claude-reset --audit     # сначала: только смотрит и сохраняет отчёт
./claude-reset             # меню
```

Запускайте **из обычного терминала, не из Claude Code**: для чистки входа Claude Code должен
быть закрыт. Не через `sudo` — инструмент сам откажется: чистятся данные вашей домашней папки.
Журнал, отчёты и копии — `~/claude-reset-data/`.

## Меню

| Пункт | Что делает |
|---|---|
| 1. Аудит | Только чтение, отчёт в файл |
| 2. Кэш | Кэш Desktop; вход и настройки остаются |
| 3. Сброс состояния | Выход из Desktop; `claude_desktop_config.json` и расширения остаются |
| 4. Все данные Desktop | Всё в `~/.config/Claude`, `~/.config/Claude-3p`, `~/.cache/Claude`; по выбору — `sudo apt remove claude-desktop`. Слово УДАЛИТЬ |
| 5. Без следов входа | Desktop, вход Claude Code (`claude auth logout`, токены, данные аккаунта в `.claude.json`), данные сайтов Claude в браузерах Linux. Слово УДАЛИТЬ |
| 6. Проверка остатков | Что осталось |
| 7. Диагностика Claude Code | Только чтение |

## Что не трогается никогда

`~/.claude` (кроме файлов входа в пункте 5), `~/.local`, `~/projects`, любые папки с `.git` или
`CLAUDE.md`, ваши `~/.bashrc` / `~/.profile` (строки с токенами только показываются), всё, что
лежит за символьной ссылкой. Процессы инструмент не завершает — только просит закрыть.

## WSL

Вход в Claude из WSL идёт через браузер Windows: его следы убирает Windows-версия (пункт 5).
Вход Desktop на обычном Linux хранится в связке ключей (GNOME Keyring / KWallet) — эту запись
инструмент не трогает и подсказывает, где удалить вручную.

## Для разработчика

`tests/run.sh` — `unittest` в песочнице: `HOME` подменён на временную папку, системный адаптер —
заглушка. На машине разработчика инструмент против настоящих данных не запускается.
