# Claude Traffic Control: меньше телеметрии, Claude Code работает

Как выключить необязательную телеметрию и фоновую активность Claude — без вреда для работы Claude Code

## 1. Главное за минуту

- **Что это.** Модуль к ClaudeReset для Windows: выключает необязательную телеметрию Claude Code официальными настройками и точечно блокирует то, что документация называет необязательным.
- **Главное правило — Claude Code должен работать.** Вход, запросы, ответы и MCP-серверы модуль не блокирует никогда.
- **Честное ограничение.** Собственная телеметрия Anthropic идёт на тот же адрес, что и ваша работа (`api.anthropic.com`). Сетью её не отделить — только официальной настройкой, а у неё есть цена (раздел 3).
- **Всё обратимо.** Кнопка RESTORE DEFAULTS возвращает настройки и снимает только свои правила брандмауэра.
- **Трафик не читается.** Модуль видит только адреса, порты и процессы. Содержимое HTTPS не расшифровывается, сертификаты не подменяются. IP, DNS, VPN и маршруты не меняются.

## 2. Что Claude Code отправляет — по документации Anthropic

| Что | Куда | Что внутри |
|---|---|---|
| Метрики | `api.anthropic.com` и `http-intake.logs.us5.datadoghq.com` | Задержки, надёжность, частота использования. По документации — без вашего кода, промптов и путей к файлам |
| Отчёты об ошибках | `browser-intake-us5-datadoghq.com` | Тексты ошибок самого Claude Code; секреты, пути и почта вырезаются до отправки |
| `/feedback`, `/bug`, `/share` | Anthropic | Копия переписки с кодом — только когда вы сами вызвали команду |
| Опросы «How is Claude doing?» | Anthropic | Оценка сессии |

Источник: code.claude.com/docs — разделы «Data usage», «Network configuration», «Environment variables».

## 3. Режимы

| | SAFE CODE MODE | STRICT MODE | RESTORE DEFAULTS |
|---|---|---|---|
| Отчёты об ошибках, `/feedback`, опросы | выключены официально | выключены | как было |
| Метрики в Datadog | блок в брандмауэре | выключены официально | как было |
| Метрики Anthropic | идут (общий канал с работой) | выключены официально | как было |
| Фон Claude Desktop | выключен: служба Cowork остановлена и запускается вручную | выключен | как было |
| Работа Claude Code | полная | без функций из списка ниже | полная |

**Цена STRICT.** Официальный выключатель метрик (`DISABLE_TELEMETRY`) выключает и загрузку флагов функций. Пропадают: `/restart`, синхронизация навыков и плагинов из claude.ai, MCP tasks, Code Mode, советник (advisor), `claude import`, `/skill-doctor`; Remote Control — возможно. Если пользуетесь чем-то из этого — оставайтесь на SAFE.

## 4. Как запустить

1. Модуль лежит в той же папке, что и ClaudeReset. Запуск — **`TrafficControl.cmd`** или пункт **10** в меню ClaudeReset.
2. Для сетевой части и службы Cowork запускайте **от имени администратора** (правой кнопкой мыши). Без прав модуль применит только официальные настройки и скажет об этом.
3. Нажмите **1** (SAFE) или **2** (STRICT). Модуль покажет, что изменится, и спросит «Применить?».
4. Согласитесь на проверку: модуль отправит **один короткий тестовый запрос** в Claude Code (немного лимита) и покажет итог.

## 5. Карточка CLAUDE TRAFFIC CONTROL

**Статусы:**

- **PROTECTED** — настройки прочитаны обратно из каждого файла и Claude Code ответил на тестовый запрос во всех местах, где он установлен. Бывает только в STRICT.
- **PARTIALLY PROTECTED** — часть необязательного не выключить без потери функций (в SAFE это метрики Anthropic), тестовый запрос не отправлялся или один из файлов настроек сейчас недоступен (например, WSL выключен).
- **NOT PROTECTED** — режим не применён, настройки не на месте или файлов настроек Claude Code не нашлось.
- **ERROR** — Claude Code где-то не ответил или правило оказалось без привязки к программе. Модуль скажет, где именно. Если это началось после режима — нажмите **3 RESTORE DEFAULTS**.

Строка «Телеметрия» в карточке говорит, есть ли на самом деле сетевой блок Datadog. Если правил нет, там будет «НЕ заблокированы сетью» и причина: нет прав администратора, адреса не определились или Claude Code в Windows запущен через node.

Если в строке «Режим» написано **«откат не завершён»**, RESTORE сделал не всё: нужны права администратора или включённый WSL. Исходные настройки модуль хранит до тех пор, пока не вернёт их, — повторите RESTORE.

**Кнопки:**

| Кнопка | Что делает |
|---|---|
| 1 SAFE / 2 STRICT | Применить режим, показав изменения заранее |
| 3 RESTORE DEFAULTS | Вернуть всё, что менял модуль |
| 4 NETWORK AUDIT | Наблюдать соединения Claude Code заданное время |
| 5 VIEW LOGS | Последние строки журнала |
| 6 Проверить сейчас | Проверка с тестовым запросом или без |
| 7 Claude Desktop | Включить или снять полный сетевой блок Desktop |

## 6. NETWORK AUDIT — как читать таблицу

Колонки: время, где (Windows или WSL), процесс, PID, адрес, хост, порт, протокол, класс, статус.

- **Классы:** CORE — работа, AUTH — вход, UPDATES — обновления, TELEMETRY — метрики, DIAGNOSTICS — отчёты об ошибках, UNKNOWN — не опознано.
- **Хост** показан, только если адрес достоверно совпал при проверке DNS.
- **Статусы:** ALLOWED — соединение установлено, BLOCKED — попытка соединения остановлена правилом модуля, UNKNOWN — не опознано. Неизвестное модуль не блокирует — решение за вами.
- **Как заметить утечку.** Если видите строку с классом TELEMETRY или DIAGNOSTICS в статусе ALLOWED, телеметрия прошла мимо блока. Например, её отправила программа, которой нет в правиле. Нажмите свой режим ещё раз, а если строка повторяется — пришлите журнал.
- **Что такое «не замечено».** Модуль опрашивает соединения раз в секунду, поэтому короткое соединение может проскочить между опросами. Отсюда формулировка «не замечено», а не «не было».

Таблица сохраняется в `%LOCALAPPDATA%\ClaudeTrafficControl\monitor-<дата>.csv`.

## 7. Важно знать

- **WSL.** Правило брандмауэра для WSL ставится, только если в WSL настроен Claude Code. Оно действует на всю виртуальную машину WSL: другие программы внутри WSL тоже не достучатся до этих адресов Datadog. Модуль предупреждает об этом до применения. На Windows без брандмауэра Hyper-V (до Windows 11 22H2) для WSL работают только настройки.
- **VPN и прокси.** Если DNS отдаёт служебные адреса (так делают некоторые VPN с подменой адресов), модуль такие адреса не блокирует и пишет об этом: завтра под ними может оказаться рабочий адрес Claude.
- **После обновлений.** После обновления Claude Code или Claude Desktop нажмите свой режим ещё раз: пути программ и адреса Datadog могут смениться.
- **Полный блок Desktop** (кнопка 7) отключает Desktop от сети целиком, по всем протоколам: он перестанет работать онлайн. Claude Code это не затронет. После обновления Desktop карточка напишет «блок устарел» — включите блок снова.
- **Где хранится состояние.** Журнал и исходные настройки лежат в `%LOCALAPPDATA%\ClaudeTrafficControl`, поэтому откат работает, даже если папку с утилитой перенесли.

## 8. Если Claude Code перестал работать

1. Откройте карточку и нажмите **3 RESTORE DEFAULTS**.
2. Согласитесь на проверку тестовым запросом.
3. Если не помогло, пришлите файл `%LOCALAPPDATA%\ClaudeTrafficControl\TrafficControl.log`.
