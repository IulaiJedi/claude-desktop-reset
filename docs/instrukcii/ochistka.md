# ClaudeReset: очистка Claude Desktop на Windows

Как почистить кэш, сбросить или полностью удалить данные Claude Desktop — и не задеть Claude Code, проекты и память

## 1. Главное за минуту

- **Что это.** Утилита для Windows: проверяет, что Claude Desktop хранит на компьютере, делает резервную копию и чистит данные по уровням — от кэша до «как новый».
- **Что она не трогает.** Claude Code (папки `.claude` и `.local`), ваши проекты, `CLAUDE.md`, память, историю переписок, Git-репозитории, диски WSL, другие программы и настройки Windows.
- **Ничего без вашего «да».** Перед любым удалением утилита показывает список: что, где, сколько места, чем рискуете. Всё, что она сделала, записано в журнал.
- **Начинайте с аудита.** Он ничего не меняет — только показывает, что нашёл.

## 2. Что нужно

| Что | Заметка |
|---|---|
| Windows 10 или 11 | Встроенного Windows PowerShell хватает, ставить ничего не нужно |
| Права администратора | Нужны для полной очистки: остановить службу Cowork и убрать её логи. Без них утилита работает, но часть файлов останется — она об этом скажет |
| Закрытый Claude Desktop | Утилита сама попросит закрыть его перед удалением |

## 3. Как запустить

1. Распакуйте архив в любую папку, например на рабочий стол. Рядом со скриптом появится папка `ClaudeReset-<имя компьютера>`: в ней журнал, отчёты и резервные копии.
2. **Первым запустите `audit.cmd`.** Он ничего не меняет. В конце скажет, где лежит отчёт.
3. Для работы запускайте `run.cmd`. Для полной очистки — правой кнопкой мыши → «Запуск от имени администратора».

Если Windows предупреждает о неизвестном издателе: правой кнопкой по файлу → «Свойства» → поставьте галочку «Разблокировать».

## 4. Меню — что делает каждый пункт

| Пункт | Что делает | Когда нужен |
|---|---|---|
| 1. Аудит | Только смотрит и сохраняет отчёт | Всегда первым |
| 2. Кэш | Удаляет кэш Desktop. Вход и настройки остаются | Desktop тормозит или странно показывает страницы |
| 3. Сброс состояния | Выход из аккаунта, Desktop как после установки. Настройки MCP-серверов и расширения остаются | Нужно войти в другой аккаунт или Desktop «залип» |
| 4. Все данные Desktop | Всё, что Desktop хранит, в том числе вне своей папки. По желанию — и само приложение | Удалить Desktop начисто |
| 5. Без следов входа | Desktop целиком, вход Claude Code, следы Claude в браузерах | Чистая установка, передача компьютера другому человеку |
| 6. Переустановка | Копия → удаление приложения → проверка остатков → установка → сверка Claude Code | Переставить Desktop, не потеряв настройки MCP |
| 7. Проверка остатков | Что осталось после очистки | После пунктов 4–6 |
| 8. Диагностика Claude Code | Где установлен, какая версия, есть ли вход — ничего не меняет | Разобраться, почему Claude Code ведёт себя странно |
| 9. Папка с журналом | Открывает журнал, отчёты и копии | — |
| 10. Claude Traffic Control | Второй модуль — меньше телеметрии. Отдельная инструкция | — |

Пункты 4 и 5 спрашивают подтверждение словом **УДАЛИТЬ** — случайно нажать не получится.

## 5. Пункт 5 «Без следов входа» — по шагам

Нужен, когда после очистки Claude должен ставиться и входить как впервые.

1. **Выход на сервере.** Удаление файлов не завершает вход на серверах Anthropic. Выйти везде можно на claude.ai: Settings → Account → Log Out. **Это выкинет из аккаунта все ваши устройства** — и этот компьютер, и остальные. Если вы только тестируете утилиту, шаг можно пропустить.
2. **Закрыть программы.** Claude Desktop, все окна Claude Code и браузеры. Edge часто работает в фоне — закройте его в трее или в диспетчере задач. Браузеры можно пропустить клавишей `s`, тогда их следы останутся.
3. **Удалить ли само приложение.** Рекомендую «да»: потом поставите начисто.
4. **Сохранить ли список MCP-серверов.** Сохраняется только список, без данных аккаунта.
5. **План и слово УДАЛИТЬ.** Утилита покажет всё, что удалит, и выполнит это только после слова.
6. **Переменные с ключами.** Если в Windows заданы переменные с токенами Claude, утилита спросит про каждую отдельно.
7. **Браузер.** Куки и данные сайтов Claude утилита убирает сама. Общую базу сайтов (Local Storage) безопасно чистит только сам браузер: утилита подскажет, где кнопка, — «Настройки → Конфиденциальность → Данные сайтов → найти claude.ai, claude.com, anthropic.com → Удалить» — и потом проверит.
8. **Ваши копии.** Если в папке пользователя лежат ваши архивы с настройками Claude, утилита покажет их и спросит про каждый.
9. **Проверка остатков** — итог: «чисто» или список того, что осталось и почему.

## 6. Что останется — и это нормально

- **Claude Code** теряет только вход: переписки, `CLAUDE.md`, память, навыки и настройки остаются.
- **История браузера, сохранённые пароли и кэш страниц** не трогаются — их чистят средствами браузера, если нужно.
- **Служебные записи Windows о приложении** (уведомления, плитки) Windows убирает сама.
- **Если папка Desktop оказалась ссылкой** на другое место, утилита по ней не пойдёт и скажет об этом.

## 7. Резервные копии и журнал

- **Где.** Копии лежат в `ClaudeReset-<компьютер>\backup`, отчёты — в `reports`, журнал всех действий — в `journal.log`.
- **Чего в копиях нет.** Токенов в них нет.
- **Что в них есть.** Сессии и логи Desktop, а в именах папок — номера аккаунта. Храните их как личные данные и удалите, когда станут не нужны.

## 8. Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| «Отказано защитой» в отчёте | Это нормально: утилита отказалась трогать путь вне своего списка. Подробности — в журнале |
| Ошибки удаления файлов виртуальной машины Cowork | Запустите `run.cmd` от имени администратора и повторите |
| Приложение не удалилось при переустановке | Утилита остановится, не тронув данные. Повторите от имени администратора |
| Claude Code ведёт себя странно | Пункт 8 «Диагностика», потом пункт 7 |
