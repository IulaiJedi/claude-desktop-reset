# Claude на чистом компьютере: в каком порядке использовать ClaudeReset и Traffic Control

Две утилиты в одной папке: что делать сначала, что потом, и как не помешать одной другой

## 1. Главное за минуту

- **ClaudeReset** чистит: кэш, вход, данные Claude Desktop, следы входа в браузерах.
- **Claude Traffic Control** настраивает: выключает необязательную телеметрию у работающего Claude Code.
- **Порядок всегда такой:** сначала чистка → потом установка и вход → потом Traffic Control → потом проверка.
- **Почему так.** Чистка выходит из аккаунта, а проверке Traffic Control нужен Claude Code, который уже вошёл и отвечает.

## 2. Что сделать — чек-лист

- [ ] Распаковать архив, запустить `audit.cmd`
- [ ] Почистить нужным пунктом ClaudeReset
- [ ] Проверить остатки
- [ ] Установить Claude заново и войти
- [ ] Включить режим Traffic Control
- [ ] Пройти проверку с тестовым запросом
- [ ] Сохранить отчёты

## 3. Полный сценарий: «чисто и тихо»

| Шаг | Где | Что делать |
|---|---|---|
| 1 | ClaudeReset → `audit.cmd` | Посмотреть, что есть на компьютере. Ничего не меняется |
| 2 | ClaudeReset → `run.cmd` от администратора → пункт **5** | Чистка без следов входа: выход на claude.ai, закрыть программы, удалить приложение, слово УДАЛИТЬ, кнопка браузера для данных сайтов |
| 3 | ClaudeReset → пункт **7** | Проверка остатков. Должно быть «чисто» или понятный список |
| 4 | claude.ai/download, терминал | Поставить Claude Desktop и/или Claude Code, войти в аккаунт |
| 5 | `TrafficControl.cmd` от администратора | **1 SAFE** — если нужны все функции. **2 STRICT** — если метрики важнее функций |
| 6 | Traffic Control | Согласиться на проверку: тестовый запрос, статус PROTECTED или PARTIALLY PROTECTED |
| 7 | Traffic Control → **4 NETWORK AUDIT**, 60 секунд при работающем Claude Code | Убедиться, что Datadog в статусе BLOCKED или не появляется |

## 4. Другие сценарии

**Только тише, без чистки.** Сразу Traffic Control: шаги 5–7. ClaudeReset не нужен.

**Desktop сломался, вход не нужен заново.** ClaudeReset: пункт **2** (кэш) или **3** (сброс состояния). Traffic Control трогать не нужно.

**Переустановить Desktop.** ClaudeReset: пункт **6**. Потом в Traffic Control нажмите свой режим ещё раз — у нового Desktop другие пути программ.

**Передаю компьютер другому человеку.** ClaudeReset: пункт **5**, затем Traffic Control: **3 RESTORE DEFAULTS**, чтобы новый владелец получил Claude с настройками по умолчанию.

**Claude Code перестал отвечать после Traffic Control.** Traffic Control: **3 RESTORE DEFAULTS** и проверка. Если не помогло — ClaudeReset, пункт **8**: диагностика Claude Code.

## 5. Как утилиты влияют друг на друга

- **Чистка не снимает режим Traffic Control.** Его настройки живут в настройках Claude Code (`settings.json`), а чистка Claude Code их не трогает: забирает только вход. Правила брандмауэра тоже остаются.
- **Хотите на чистом компьютере всё по умолчанию** — после чистки нажмите в Traffic Control **3 RESTORE DEFAULTS**.
- **Traffic Control не мешает чистке.** Он не трогает данные Desktop, вход и браузеры.
- **Что делать после чистки с удалением Desktop.** Если чистка удалила Claude Desktop, служба Cowork исчезает вместе с ним. При откате Traffic Control скажет, что вернуть её тип запуска нельзя, — это нормально.
- **Журналы у утилит раздельные.** ClaudeReset пишет в папку `ClaudeReset-<компьютер>` рядом со скриптом, Traffic Control — в `%LOCALAPPDATA%\ClaudeTrafficControl`.

## 6. После обновлений Claude

- **Обновился Claude Code или Desktop** — откройте Traffic Control и нажмите свой режим ещё раз: пути программ и адреса могут смениться.
- **Раз в месяц** запускайте `audit.cmd` и **4 NETWORK AUDIT**, чтобы увидеть, не появилось ли новых соединений со статусом UNKNOWN.
