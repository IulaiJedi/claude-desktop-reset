# ClaudeReset для Ubuntu и WSL

Как почистить Claude Desktop для Linux и следы входа в Claude — не задев Claude Code, проекты и память

## 1. Главное за минуту

- **Что это.** Утилита для Ubuntu (и Ubuntu внутри WSL на Windows): проверяет, что Claude хранит в домашней папке, делает резервную копию и чистит по уровням — от кэша до «без следов входа».
- **Что не трогается.** Claude Code: переписки, `CLAUDE.md`, память, навыки, настройки. Папки `~/.local` и `~/projects`, Git-репозитории, ваши файлы `~/.bashrc` и `~/.profile`, всё, что лежит за символьной ссылкой.
- **Ничего без вашего «да».** Перед удалением утилита показывает список: что, где, размер, риск. Всё записано в журнал `~/claude-reset-data/journal.log`.
- **Начинайте с аудита** — он ничего не меняет.

## 2. Что нужно

| Что | Заметка |
|---|---|
| Ubuntu 22.04 и новее или Ubuntu в WSL | Python 3 уже есть в системе, ставить ничего не нужно |
| Обычный терминал | Не окно Claude Code: для чистки входа Claude Code должен быть закрыт |
| Свой пользователь | Не через `sudo`: утилита откажется сама — чистятся данные вашей домашней папки |

## 3. Как запустить

1. Распакуйте архив, откройте терминал в папке `linux`.
2. Сначала аудит: `./claude-reset --audit`. В конце он скажет, где отчёт.
3. Меню: `./claude-reset`.

## 4. Меню

| Пункт | Что делает |
|---|---|
| 1. Аудит | Только смотрит и сохраняет отчёт |
| 2. Кэш | Кэш Claude Desktop. Вход и настройки остаются |
| 3. Сброс состояния | Выход из Desktop, Desktop как новый. Настройки MCP-серверов и расширения остаются |
| 4. Все данные Desktop | Всё в `~/.config/Claude`, `~/.config/Claude-3p`, `~/.cache/Claude`. По желанию — удаление пакета `claude-desktop` (спросит пароль в этом же окне). Слово **УДАЛИТЬ** |
| 5. Без следов входа | Desktop, вход Claude Code, данные сайтов Claude в браузерах Linux. Слово **УДАЛИТЬ** |
| 6. Проверка остатков | Что осталось и что нужно сделать руками |
| 7. Диагностика Claude Code | Где установлен, версия, есть ли вход — ничего не меняет |

## 5. Пункт 5 «Без следов входа»

1. **Выход на сервере.** На claude.ai: Settings → Account → Log Out. Это выкинет из аккаунта **все** ваши устройства. Шаг можно пропустить клавишей Enter.
2. **Закройте** Claude Desktop, все окна Claude Code и браузеры. Утилита проверит это и перед удалением спросит ещё раз.
3. **Пакет Desktop** — удалить или оставить.
4. **Список MCP-серверов** — сохранить без данных аккаунта.
5. **План и слово УДАЛИТЬ.**
   - Первым выполняется штатный `claude auth logout`.
   - Потом удаляются данные Desktop и файлы входа Claude Code.
   - Из `~/.claude.json` уходят только данные аккаунта — проекты и MCP-серверы остаются.
6. **Ваши копии.** Если в домашней папке лежат ваши архивы с настройками Claude, утилита спросит про каждый.
7. **Проверка остатков** и итог.

## 6. Что делается руками — утилита подскажет

- **Связка ключей.** Вход Claude Desktop на Linux хранится в GNOME Keyring или KWallet. Откройте «Пароли и ключи» и удалите записи Claude.
- **Токены в профиле оболочки.** Если `ANTHROPIC_API_KEY` или `CLAUDE_CODE_OAUTH_TOKEN` прописаны в `~/.bashrc`, `~/.zshrc` или подобных файлах, утилита покажет файл и строку. Удалите строку сами.
- **Данные сайтов в браузере.** Общую базу сайтов (Local Storage) безопасно чистит только сам браузер: «Настройки → Конфиденциальность → Данные сайтов → claude.ai, claude.com, anthropic.com → Удалить».
- **История браузера, сохранённые пароли и кэш страниц** — по желанию, средствами браузера.

## 7. Если вы в WSL

- **Вход шёл через Windows.** Вход в Claude из WSL открывается в браузере Windows, поэтому следы в браузере убирает Windows-версия ClaudeReset (пункт 5).
- **Сеть из WSL.** Телеметрию Claude Code в WSL настраивает Windows-модуль Claude Traffic Control.

## 8. Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| «Отказано защитой» | Утилита отказалась трогать путь вне своего списка — так и задумано. Подробности в журнале |
| «Сначала закройте: Claude Code» | Закройте все окна Claude Code и запустите утилиту из обычного терминала |
| Копия сделана с ошибками | Утилита остановится и спросит, продолжать ли. Ошибки перечислены на экране |
