Hyper-V, смена типа службы, запись настроек, `claude -p`. Первый живой прогон — у оператора:
`TrafficControl.cmd` от администратора → SAFE → проверка с тестовым запросом.

## 21.11.2026 — Windows-версия ClaudeReset

**Готово:** Windows-версия, `main` на `5d94b19`. `windows/ClaudeReset.ps1` + `run.cmd`,
`audit.cmd`, `README.md`. Архив для оператора: `C:\Users\iulaijedi\Downloads\ClaudeReset-windows.zip`.

**Проверено:** 56 тестов Pester 3.4 на муляжах (`windows/tests/run.sh`), на `main` после
слияния — 56/56. Синтаксический разбор файла самим PowerShell: 0 ошибок, все вызовы `*-Cr*`
определены. Ревью второй моделью (Fable), два прохода: 13 находок, 13 подтвердились и
исправлены; затем 5 мелких, 4 исправлены, 1 оставлена намеренно (ниже).

**Не проверено и проверить нельзя здесь:** настоящий системный адаптер `New-CrRealSys`
(Get-AppxPackage, CIM, реестр, robocopy/icacls, Remove-AppxPackage) ни разу не исполнялся —
запуск против настоящих данных на этой машине запрещён оператором. Первый живой прогон —
оператор на другом устройстве, начиная с `audit.cmd` (только чтение).

**Сознательно оставлено:**
- если `%USERPROFILE%\.claude` — ссылка (junction), чистка входа Claude Code получает отказ
  «путь проходит через ссылку»; штатный `claude auth logout` при этом работает, итог мастера
  честно пишет «сделано не всё»;
- `.claude.json` переписывается без копии для отката: копия с данными аккаунта сама была бы
  следом входа. Замена атомарная, результат перечитывается до замены.
