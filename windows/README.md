# ClaudeReset для Windows

Аудит, резервная копия и сброс локальных данных Claude Desktop. Claude Code,
проекты, CLAUDE.md, память и история переписок при этом не страдают. Ещё есть
чистка «без следов входа»: она убирает вход в Desktop, Claude Code и следы
сайтов Claude в браузерах.

## Как запустить

1. Скопируйте папку `windows` на компьютер. Журнал, отчёты и копии ложатся в
   папку `ClaudeReset-<компьютер>` рядом со скриптом.
2. **Первым запустите `audit.cmd`.** Он ничего не меняет: показывает, что
   нашёл, и сохраняет отчёт.
3. Меню — `run.cmd`. Чтобы инструмент мог остановить службу Cowork и убрать
   её логи, запустите `run.cmd` от имени администратора (правая кнопка мыши).

Если Windows ругается на «неизвестного издателя»: Свойства файла → Разблокировать.

## Меню

| Пункт | Что делает |
|---|---|
| 1. Аудит | Только чтение. Отчёт — в `ClaudeReset-<компьютер>\reports` |
| 2. Кэш | Удаляет кэш Desktop. Вход и настройки остаются |
| 3. Сброс состояния | Выход из Desktop, Desktop как новый. Настройки MCP-серверов и расширения Desktop остаются |
| 4. Все данные Desktop | Всё, что Desktop хранит, включая то, что лежит вне его папки. По желанию — удаление самого приложения. Подтверждение словом УДАЛИТЬ |
| 5. Без следов входа | Desktop целиком, вход Claude Code, следы Claude в браузерах. Подтверждение словом УДАЛИТЬ |
| 6. Переустановка | Копия, удаление приложения, проверка остатков, установка, сверка Claude Code |
| 7. Проверка остатков | Что осталось от Desktop, входа и браузеров |
| 8. Диагностика Claude Code | Только чтение: установки, версии, вход, файлы |

Перед каждым удалением инструмент показывает список: что, где, размер, риск,
последствие. Без «да» ничего не удаляется. Каждое действие записано в
`ClaudeReset-<компьютер>\journal.log`.

## Что не трогается никогда

`%USERPROFILE%\.claude` (кроме файлов входа в пункте 5), `.claude.json` (в пункте 5
из него убираются только данные аккаунта), `%USERPROFILE%\.local`, папки с
`.git` или `CLAUDE.md`, диски WSL, чужие приложения, системные настройки Windows.

## Важно про пункт 5

- Шаг «Log Out на claude.ai» выкидывает из аккаунта **все** устройства, включая
  этот компьютер. Для теста его можно пропустить.
- Браузеры должны быть закрыты. Общую базу сайтов (Local Storage) безопасно чистит
  только сам браузер: инструмент подскажет, где кнопка, и проверит результат.
- Свои архивы с настройками Claude инструмент только показывает. Удаляет —
  по отдельному «да» на каждый. Переменные среды с токенами — тоже по отдельному «да».
- Инструмент чистит куки и данные сайтов Claude. История посещений, сохранённые
  пароли и кэш страниц браузера он не трогает — их чистят средствами браузера.
- Если папка данных Desktop оказалась ссылкой на другое место, инструмент по ней
  не пойдёт и скажет об этом — такие данные разбираются вручную.

## Резервные копии

Копии пунктов 3, 4 и 6 лежат в `ClaudeReset-<компьютер>\backup`. В них нет
токенов, но есть сессии и логи Desktop с номерами аккаунта в именах папок —
храните их как личные данные и удалите, когда станут не нужны. Пункт 5 сохраняет
только список MCP-серверов.

## Для разработчика

Тесты (Pester 3.4, встроен в Windows) работают только на муляжах во временной папке:
`tests\run-tests.cmd`, из WSL — `tests/run.sh`. Файлы `.ps1` хранятся в UTF-8 с BOM —
иначе Windows PowerShell 5.1 ломает кириллицу.
